# Projeto Integrador II – Doce Encanto

## Cupcakes Gourmet

Projeto acadêmico do curso de Engenharia de Software.

Aplicativo Android desenvolvido em Java, utilizando o Android Studio, iniciado no Projeto Integrador I e aprimorado no Projeto Integrador II.

As melhorias incluem identidade visual, logomarca, catálogo de cupcakes, aumento das letras e ajustes realizados a partir das sugestões dos usuários.
